Платформа локального Docker-хостингу працює. Ви можете підключати власні проєкти через зовнішню мережу local-hosting.

Підключити новий проєкт

docker compose up -d

Додайте до свого compose.yaml мережу local-hosting та Traefik labels. Домен з'явиться автоматично.
