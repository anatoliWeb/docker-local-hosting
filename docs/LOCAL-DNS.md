# Локальний DNS (майбутнє)

Наразі MVP використовує файл `hosts` для резолвінгу доменів.

## Обмеження hosts

- Кожен новий домен — окремий запис.
- Немає wildcard.
- Потрібні права адміністратора.
- Потрібно оновлювати на кожному клієнтському ПК.

## Варіанти DNS

### DNS на роутері
- `*.home.arpa` → IP центрального сервера.

### AdGuard Home / Pi-hole
- Docker-контейнери з підтримкою wildcard.
- Фільтрація реклами + DNS.
- Окремий проєкт, не входить у базовий compose.

### CoreDNS / Dnsmasq
- Максимальна гнучкість.
- Вимагає досвіду.

## Приклад правила

Для AdGuard Home:
```
*.home.arpa 192.168.1.100
```

Після DNS hosts більше не потрібен.
